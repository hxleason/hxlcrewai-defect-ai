[标准: GB/T 19624-2019] 第5.3条
缺陷类型: 裂纹
当裂纹深度与壁厚之比 ≥ 0.3 时，风险等级评为高风险(≥7)。
措施: 必须进行安全评估，必要时返修或报废。
检查建议: 采用 TOFD 或相控阵超声精确测量裂纹扩展。

[标准: GB/T 19624-2019] 第5.4条
缺陷类型: 裂纹
若裂纹深度 ≥ 2mm，需记录并监控。
措施: 建立裂纹监测台账，每季度复测一次。
检查建议: 优先选用超声横波检测。

[标准: API 579-1/ASME FFS-1] 第3篇
缺陷类型: 点蚀/腐蚀
当点蚀深度/壁厚 ≥ 0.5 时，剩余强度因子可能不足，需评估剩余寿命。
措施: 进行 FFS 评定，确定 MAWP 和剩余寿命。
检查建议: 建议采用高频导波或声发射进行大面积腐蚀筛查。

[标准: API 579-1] 第4篇
缺陷类型: 夹杂/气孔
单个夹杂长度 ≤ 10mm 时，一般不影响使用，但需注意密集区。
措施: 若发现密集夹杂，应按体积占比评估。
检查建议: 使用射线检测进行体积类缺陷定位。
